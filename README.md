# MyPaint — 탭과 고스트 트레이싱이 있는 그림판

Windows 그림판을 본떠 MFC 대화 상자 기반으로 만든 그림판입니다. 연필, 브러시, 도형 같은 그림판의 기본 그리기 기능에 더해, 그림판에 없는 아이디어 두 가지를 넣었습니다.

## 나만의 아이디어

### 1. 크롬 스타일 탭

Windows 그림판은 창 하나에 그림을 하나만 엽니다. 여러 그림을 비교하거나 오가며 그리려면 창을 여러 개 띄워야 합니다.

MyPaint는 브라우저처럼 한 창 안에서 여러 그림을 탭으로 엽니다. 그림은 탭마다 따로 갖고, 도구와 색은 모든 탭이 함께 씁니다. 그래서 탭을 바꿔도 같은 붓과 색으로 바로 이어 그릴 수 있습니다. 자세한 조작은 [탭](#탭--나만의-아이디어-1)에 있습니다.

### 2. 고스트 트레이싱

종이에 그릴 때는 밑그림을 라이트박스나 트레이싱지 아래에 두고 따라 그립니다. 그림판에는 레이어나 투명도가 없어서 사진이나 밑그림을 따라 그리기 어렵습니다.

MyPaint는 탭을 이용해 이 문제를 풉니다. 한 탭에 원본을 열어 두면, 다른 탭에서 그 원본이 종이 아래에 비치듯 반투명하게 보입니다. 원본은 화면에만 겹쳐 보이므로 저장한 파일에는 내가 그린 선만 남습니다. 자세한 조작은 [고스트 트레이싱](#고스트-트레이싱--나만의-아이디어-2)에 있습니다.

## 빌드와 실행

필요한 것: Windows 10 이상, Visual Studio 2022 (MSVC v143, "C++를 사용한 데스크톱 개발" 워크로드와 MFC 구성 요소)

```powershell
msbuild MyPaint.sln /t:Rebuild /p:Configuration=Release /p:Platform=x64
# → x64\Release\MyPaint.exe
```

- MFC를 정적 라이브러리로 링크하므로 `MyPaint.exe` 하나만 있으면 따로 설치하지 않고 실행됩니다.
- 소스 파일은 UTF-8이고 `/utf-8` 옵션과 C++17로 컴파일합니다.

## 사용 방법

### 그리기

도구 묶음에서 도구를 고르고 캔버스에서 끌어 그립니다. **왼쪽 버튼은 색 1, 오른쪽 버튼은 색 2**로 그립니다.

| 도구 | 사용법 | 기본 굵기 |
| --- | --- | --- |
| 연필 | 끌어서 자유롭게 그립니다. 경계가 또렷한 선입니다. | 1px |
| 브러시 | 끌어서 부드러운 둥근 선으로 그립니다. | 8px |
| 지우개 | 끌어서 색 2로 지웁니다(어느 버튼이든). 마우스 위치에 지우개 크기가 사각형으로 보입니다. | 12px |
| 채우기 | 클릭한 곳과 같은 색으로 이어진 영역을 채웁니다. | – |
| 스포이트 | 클릭한 곳의 색을 집습니다. 왼쪽 클릭은 색 1로, 오른쪽 클릭은 색 2로 가져옵니다. | – |
| 직선 | 끌어서 그립니다. Shift를 누르면 45° 단위로 고정됩니다. | 3px |
| 사각형 | 끌어서 그립니다. Shift를 누르면 정사각형이 됩니다. | 3px |
| 타원 | 끌어서 그립니다. Shift를 누르면 원이 됩니다. | 3px |

- **굵기**: 1, 2, 3, 5, 8, 12, 16, 24, 32px 중에서 고릅니다. 굵기는 도구마다 따로 기억합니다.
- **채우기**(모양 묶음): 사각형과 타원을 그리는 방식입니다.
  - 윤곽선만: 그리는 색으로 테두리만 그립니다.
  - 윤곽선 + 색 2로 채우기: 테두리는 그리는 색, 안쪽은 반대쪽 색으로 채웁니다. 오른쪽 버튼으로 그리면 테두리가 색 2, 안쪽이 색 1이 됩니다.
  - 채우기만: 그리는 색으로 안쪽만 채웁니다.
- 지금 도구가 쓰지 않는 설정(예: 연필의 채우기 방식)은 흐리게 꺼집니다.
- **그리기 취소**: 끄는 도중 Esc나 다른 쪽 마우스 버튼을 누르면 그리기 전 상태로 돌아갑니다.
- **스크롤**: 마우스 휠은 위아래, Shift+휠은 좌우로 움직입니다.

### 색

- 색 묶음 왼쪽에 겹쳐 있는 두 칸이 **색 1**(앞)과 **색 2**(뒤)입니다. 처음에는 색 1이 검정, 색 2가 흰색이고, 이 칸을 클릭하면 두 색이 맞바뀝니다.
- 기본 색 6가지(검정, 빨강, 초록 / 흰색, 노랑, 파랑)를 왼쪽 클릭하면 색 1, 오른쪽 클릭하면 색 2가 됩니다.
- 기본 색 칸을 두 번 클릭하면 그 칸의 색을 바꿀 수 있고, 바꾼 색이 색 1이 됩니다.
- **색 편집** 단추를 누르면 색 대화 상자에서 색 1을 원하는 색으로 고릅니다.

### 탭 — 나만의 아이디어 1

| 하는 일 | 방법 |
| --- | --- |
| 새 탭 열기 (800 × 600 흰 그림) | Ctrl+T, **새 탭** 단추, 탭 표시줄의 **+**, 탭 표시줄 빈 곳 두 번 클릭 |
| 탭 바꾸기 | 탭 클릭, Ctrl+Tab(다음 탭), Ctrl+Shift+Tab(이전 탭) |
| 탭 닫기 | Ctrl+W, 탭의 **×**, 탭을 마우스 가운데 버튼으로 클릭 |

- **탭마다 따로** 갖는 것: 그림, 파일 경로, 저장 여부
- **모든 탭이 함께** 쓰는 것: 도구, 굵기, 채우기 방식, 색 1/색 2, 고스트 트레이싱 설정
- 저장하지 않은 변경이 있는 탭은 × 자리에 **●**가 보이고(마우스를 올리면 ×로 바뀜), 창 제목 앞에 `*`가 붙습니다. 스포이트처럼 그림이 실제로 바뀌지 않은 조작은 변경으로 치지 않습니다.
- 저장하지 않은 탭을 닫으면 저장할지 묻습니다. **예**는 저장하고 닫고, **아니요**는 저장하지 않고 닫고, **취소**는 닫지 않습니다. 저장 대화 상자에서 취소하거나 저장에 실패해도 닫지 않습니다.
- 보고 있던 탭을 닫으면 오른쪽 탭(마지막 탭이었다면 왼쪽 탭)으로 넘어갑니다. 하나 남은 탭을 닫으면 새 빈 탭이 생깁니다.
- 창을 닫을 때도 저장하지 않은 탭마다 묻고, 하나라도 취소하면 창을 닫지 않습니다.
- 탭이 많아지면 크롬처럼 탭 너비가 줄어들고, 너무 좁아지면 × 단추는 선택된 탭에만 보입니다.

### 열기와 저장

| 하는 일 | 방법 |
| --- | --- |
| 열기 | Ctrl+O, **열기** 단추 |
| 저장 | Ctrl+S, **저장** 단추 |
| 다른 이름으로 저장 | Ctrl+Shift+S, **다른 이름으로 저장** 단추 |

**열기**

- PNG, BMP, JPEG 파일을 엽니다. 파일 형식을 "모든 파일"로 바꾸면 GIF, TIFF처럼 GDI+가 읽을 수 있는 그림도 열립니다. 여러 장으로 된 그림은 첫 장만 엽니다.
- 여러 파일을 한 번에 고를 수 있고, 파일마다 탭이 하나씩 생깁니다.
- 지금 탭이 아무것도 그리지 않은 빈 탭이면 첫 파일은 그 탭에 엽니다.
- 이미 열려 있는 파일을 고르면 다시 열지 않고 그 탭으로 갑니다.
- 투명한 부분은 흰 바탕 위에 합성합니다(Windows 그림판과 같음).
- 열지 못한 파일은 이유와 함께 한 번에 알려 줍니다.

**저장**

- 처음 저장하는 탭이면 저장 대화 상자를 띄웁니다. 기본 형식은 PNG이고 BMP, JPEG도 고를 수 있습니다.
- 한 번 저장한 탭은 다시 묻지 않고 같은 파일에 덮어씁니다.
- 형식은 확장자(.png, .bmp, .jpg, .jpeg)로 정해집니다. 확장자가 없거나 지원하지 않는 확장자면 고른 형식의 확장자를 붙입니다.
- GIF처럼 저장할 수 없는 형식으로 연 그림은 처음 저장할 때 같은 이름의 PNG로 저장할 곳을 묻습니다.
- **다른 이름으로 저장**은 언제나 저장할 곳을 묻습니다. 이미 있는 파일을 고르면 바꿀지 확인합니다.
- 열기와 저장 대화 상자는 지금 탭의 파일이 있는 폴더에서 시작합니다.

### 고스트 트레이싱 — 나만의 아이디어 2

다른 탭의 그림을 지금 탭에 반투명하게 비춰, 그 위에 대고 따라 그리는 기능입니다. 예를 들어 첫 탭에 사진을 열고, 그 오른쪽 새 탭에서 Ctrl+G를 누르면 사진이 옅게 비칩니다. 그 위를 따라 그린 뒤 저장하면 따라 그린 선만 저장됩니다.

| 하는 일 | 방법 |
| --- | --- |
| 켜기/끄기 | Ctrl+G, **고스트 보기** 단추 |
| 원본 탭 고정/풀기 | Ctrl+Shift+G, **원본 고정** 단추 |
| 진하기 | **진하기**의 25% / 50% / 75% 단추 (처음에는 50%) |

**어떤 탭을 비추나요**

- 원본으로 고정한 탭이 있으면 그 탭을, 없으면 **바로 왼쪽 탭**을 비춥니다.
- 고정한 탭에서 다시 Ctrl+Shift+G를 누르면 고정이 풀리고, 다른 탭에서 누르면 고정이 그 탭으로 옮겨 갑니다.
- 원본 탭 자신을 보고 있을 때는 아무것도 겹치지 않습니다. 맨 왼쪽 탭은 왼쪽 탭이 없으므로, 고정한 원본이 없으면 비추지 않습니다.
- 고정한 탭을 닫으면 고정이 풀리고 다시 왼쪽 탭을 비춥니다. 고정한 빈 탭에 파일을 열면 고정은 그 탭에 그대로 남습니다.

**어떻게 보이나요**

- 원본은 종이 아래에서 비치듯 옅게 보이고, 내가 그린 선은 그 위에 원래 색 그대로 보입니다. 검은 선은 원본 위에서도 또렷한 검정입니다.
- 두 그림은 왼쪽 위 모서리를 맞춰 겹치고, 크기가 다르면 겹치는 부분에만 비칩니다.
- 고스트는 **화면에만** 보입니다. 저장, 채우기, 스포이트는 모두 고스트 없이 내 그림만 봅니다.
- 원본 탭에서 그림을 고치면, 돌아왔을 때 고친 모습 그대로 비칩니다.

**상태 표시**

상태 표시줄의 그림 크기 오른쪽 칸에 고스트 상태가 나옵니다.

| 상태 | 표시 |
| --- | --- |
| 켜짐, 비추는 중 | `고스트 50% · 원본: 사진.png (왼쪽 탭)` 또는 `… (고정)` |
| 켜짐, 원본 탭을 보는 중 | `고스트 켜짐 · 지금 탭이 원본이라 겹치지 않음` |
| 켜짐, 비출 탭이 없음 | `고스트 켜짐 · 비출 왼쪽 탭이 없음` |
| 꺼짐, 고정한 원본이 있음 | `고스트 꺼짐 · 고정한 원본: 사진.png` |
| 꺼짐, 고정 없음 | (비어 있음) |

원본 탭의 제목 앞에는 작은 유령 아이콘이 붙습니다.

| 아이콘 | 뜻 |
| --- | --- |
| 보라색 테두리 | 왼쪽 탭이라서 비추는 중 |
| 보라색으로 채움 | 고정한 원본을 비추는 중 |
| 회색으로 채움 | 원본으로 고정했지만 고스트가 꺼져 있음 |

## 구조와 동작 원리

- **문서와 탭**: 탭 하나가 문서(`CPaintDocument`) 하나입니다. 문서는 그림 버퍼, 파일 경로, 저장 안 된 변경 여부를 갖습니다. 캔버스는 선택된 탭의 문서를 가리키기만 합니다. 도구, 굵기, 채우기 방식, 색 같은 그리기 설정은 문서가 아니라 캔버스와 팔레트가 갖고 있어서, 탭을 바꿔도 설정이 그대로 남습니다.
- **그리기**: 캔버스가 마우스 입력을 받아 지금 도구에 넘깁니다. 연필과 지우개는 GDI로 또렷하게, 브러시와 도형은 GDI+로 부드럽게(앤티에일리어싱) 그립니다. 직선, 사각형, 타원은 끄는 동안 미리보기로만 보이고, 버튼을 뗄 때 그림에 들어갑니다.
- **취소와 변경 표시**: 그리기를 시작할 때 그림을 복사해 두고, 취소하면 그 복사본으로 되돌립니다. 그리기가 끝나면 복사본과 비교해 그림이 실제로 바뀐 경우에만 탭에 변경 표시를 붙입니다.
- **화면 그리기**: 바뀐 영역만 메모리 비트맵에 그린 뒤 한 번에 화면으로 옮겨(더블 버퍼링) 깜빡임이 없습니다.
- **고스트 합성**: 화면에 옮기기 직전에, 바뀐 영역에서만 지금 그림과 원본을 곱하기(multiply) 방식으로 섞습니다. 색 채널마다 원본 값 c를 진하기 p%만큼 흰색 쪽으로 옅게 만든 f = 255 − (255 − c) × p / 100을 구하고, 지금 그림의 값에 f / 255를 곱합니다. 흰 종이에는 옅어진 원본이 보이고, 검은 선은 0 × f = 0이라 그대로 검정입니다. 문서의 픽셀은 바꾸지 않으므로 저장한 파일에는 고스트가 들어가지 않습니다.
- **파일**: 불러오기와 저장은 GDI+로 합니다. 한 변이 16,384px를 넘거나 전체가 약 6,700만 화소(64M)를 넘는 그림은 메모리를 지키기 위해 열지 않습니다.
- **고해상도 화면**: 모니터별 DPI를 인식합니다. 배율이 다른 모니터로 창을 옮기면 도구 모음과 탭을 그 배율에 맞게 다시 배치합니다.
